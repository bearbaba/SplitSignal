# SplitSignal

A GenLayer desk that pays the account catching two public pages diverge.

A funder locks GEN against two URLs and one field. Anyone can recheck.
Validators render both pages. Matching values stay AGREED. A split pays the finder.
After one hour an open watch can be refunded to the funder.
